# Security Policy

## Reporting a Vulnerability

If you find a security vulnerability in OpenTokenUsage, please report it privately. Do not open a public issue.

1. Go to the [Security Advisories page](https://github.com/PowerUserZ/OpenTokenUsage/security/advisories/new)
2. Click "Report a vulnerability"
3. Fill in the details

This keeps the report private between you and the maintainer until a fix is released.

## What to Include

- Description of the vulnerability
- Steps to reproduce
- Affected versions
- Impact assessment (what can an attacker do?)

## Response

- Acknowledgment as soon as possible, usually within a few days
- An assessment and a plan once the report is confirmed
- A fix released as soon as practical, depending on severity, with credit to you if you want it

## Scope

The following are in scope:

- The OpenTokenUsage desktop application, including its local HTTP API
- Provider plugins shipped with OpenTokenUsage
- The updater and the build and release infrastructure
- The website, [opentokenusage.app](https://opentokenusage.app)

The following are out of scope:

- Third-party provider APIs (report to the provider directly)
- Social engineering attacks
- Denial of service attacks

## Supported Versions

Only the latest release is supported with security updates. The app updates itself, so staying current is one click.
